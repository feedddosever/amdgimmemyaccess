# MenuBridge video script

Under 4:30. Record `/demo` in a 1440×900 browser window; the demo segments run from 0:00 to 2:30. The deployed demo runs on saved canned answers (`MOCK_LLM=1`): no GPU was connected in time, and the narration says so. Before recording: in `/kitchen` press "Svuota", and in `/metrics` press "Clear log". Each preset on `/demo` shows its order text with a Copy button; use exactly that text so the canned answers match.
