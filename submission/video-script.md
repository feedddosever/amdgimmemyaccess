# MenuBridge video script

Under 4:30. Record `/demo` in a 1440×900 browser window; the live demo runs from 0:30 to 2:30. Before recording: in `/kitchen` press "Svuota", and in `/metrics` press "Clear log". Each preset on `/demo` shows its order text with a Copy button; use exactly that text so the saved answers work even if the GPU is off.
